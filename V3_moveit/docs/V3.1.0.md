# V3.1.0 安装与恢复

本版在 Ubuntu 24.04 x86_64、ROS 2 Jazzy、Quest 3 和 2 号 JAKA S5 上验证。工作台包含机械臂、灵巧手、原始 SolidWorks 装配、URDF、网格、厂家控制库、现场 TCP 和负载标定、抓握方案和相机配置。现场记录覆盖 61.89 秒的双眼透视和 5358 帧有效右手柄位姿，操作员随后完成了真机遥操作。MoveIt 的 `move_group` 在退出清理时有一条既有报错，控制柜已确认 Servo 退出。[现场记录](../artifacts/quest_stereo_20261119/entry_result.json)

## 在新电脑上安装

在 Ubuntu 的本地 Linux 文件系统中解压，选择当前用户可写的目录。Release 中的安装包包含独立的 `V3_moveit/` 目录。如果使用 Git 克隆，切换到标签 `V3.1.0` 后从仓库中的同名子目录启动。[Release 下载页](https://github.com/guoqingliu666/Teleoperation-jaka-q3s/releases/tag/V3.1.0)

```bash
sha256sum --ignore-missing -c SHA256SUMS
tar --zstd -xf V3.1.0-ubuntu24.04.tar.zst
cd V3_moveit
bash INSTALL_UBUNTU.sh
bash START_OPERATOR.sh
```

安装器调用系统 apt 安装缺少的依赖，编译控制器、灵巧手驱动和显示组件。首次获取 Ubuntu 和 ROS 软件包需要网络。PyQtGraph、PyOpenGL 和本版控制所用的 JAKA、DH116 库均随工程提供。日常直接运行 `bash START_OPERATOR.sh`。也可以在本目录打开 `V3-Operator.desktop`。上位机默认进入仿真模式。

## 连接现场设备

- **机械臂**　本站控制柜为 `192.168.110.224`，原 Ubuntu 有线地址为 `192.168.110.67`，EDG 端口为 `30003`。在新电脑上用 `ip route get 192.168.110.224` 查看所用网口和 `src` 地址，将工程根目录的 `site_ubuntu.yaml` 中的 `edg_client_ip` 设置为该网口的实际地址。原机与新机同时联网时，分配各自的有线地址。本站使用 TCP1，工具和负载按本机控制柜的实际回读核对。
- **Quest**　头显启用开发者模式，用 USB 数据线连接并允许该电脑进行 USB 调试。在上位机连接 Quest 后，头显浏览器打开 `https://localhost:8443/`。首次连接时核对并确认本机证书，然后点「进入透视模式 · 三维工作台」。每台工作站首次启动会生成自己的本机证书。
- **DH116**　在「灵巧手抓握」选择 DH116 实机和实际 EtherCAT 网口，点击「连接」。如需为编译出的两只 EtherCAT 程序授予原始网口权限，执行 `sudo bash tools/setup_dh116_access.sh`。在这些程序重编译后需要重新授予该权限。C922 使用系统 V4L2 设备。
- **ZED Mini**　现场采集预设是 1920 × 1080、30 fps。需要本地深度时，安装与 CUDA 12.8 兼容的 NVIDIA 驱动，在工程中运行 `bash tools/setup_zed_runtime.sh` 和 `bash tools/setup_zed_usb.sh`。前者从厂家取得 5.5.1 SDK 并创建独立 Python 环境，也可传入已下载的对应 `.run` 文件。该工具会检查 SDK 版本并导入 Python 接口。首次使用深度模型需要网络。已附原 ZED 的序列号标定文件，换相机时使用对应序列号的标定。[Stereolabs 官方 SDK](https://www.stereolabs.com/developers/release)

## 日常遥操作

在上位机的遥操作页选「真机」，确认现场准备，按界面提示启用本次实时权限，点击启动。头显显示「可以开始遥操作」后，**握住右侧 Grip 控制 TCP1，松开暂停**。右手扳机的行程控制当前灵巧手抓握动作。启动时会核对当次的硬件反馈、工具、负载和状态。「检查与验收」页供开发调试时单独使用。

## 恢复到这一版

恢复源代码和正常的工作环境时，可以将标签 `V3.1.0` 克隆到一个新目录，或重新解压同一版安装包，再运行安装器。已安装的 Ubuntu 软件包版本记录在 `reference/v3.1.0/ros-packages.txt`。

Release 还提供两组附件。公开的 `V3.1.0-recordings.tar.zst.part-*` 包含原工作站的采集数据、历史测试、运行日志和交接记录。`V3.1.0-workstation.tar.zst.gpg.part-*` 是原工作站工程的加密快照，包括当时的构建、安装、虚拟环境、缓存、站点配置、本机证书和工程引用的外部手模型及接口。恢复密钥由项目负责人单独保存。系统用户、USB 授权、内核、显卡驱动和以太网权限属于操作系统，需要在目标机配置。

从同一 Release 下载目标组的全部分卷和 `SHA256SUMS`。以下命令在空目录中运行。先验分卷，再解压。

```bash
set -o pipefail
grep ' V3.1.0-recordings.tar.zst.part-' SHA256SUMS | sha256sum -c -
mkdir records
cat V3.1.0-recordings.tar.zst.part-* | zstd -dc | tar -xpf - -C records
```

需要恢复原工作站时，将负责人保存的密钥文件放在只有本人可读的位置。下面的命令会还原 `V3_moveit/` 和它引用的 `灵巧手_DH116/` 资料。原工作站构建缓存包含绝对路径；在其他路径编译请使用上面的安装包。

```bash
set -o pipefail
grep ' V3.1.0-workstation.tar.zst.gpg.part-' SHA256SUMS | sha256sum -c -
mkdir restored
cat V3.1.0-workstation.tar.zst.gpg.part-* | \
  gpg --batch --pinentry-mode loopback --passphrase-file /path/to/LOCAL-RECOVERY-KEY.txt --decrypt | \
  zstd -dc | tar -xpf - --no-same-owner -C restored
```
