# 本地模型文件

公开源码仓库不包含 JAKA S5、快换、法兰和 DH116 的厂家/合作方 CAD、STL 与 URDF 文件，避免在分发授权未确认时误公开。

本机运行时使用以下两个目录：

- `JakaS5/`：JAKA S5 的 URDF 与 `Link_00.STL`—`Link_06.STL`。
- `CompleteEndEffector/`：机械臂、快换、连接法兰与 DH116 的完整末端模型及装配描述。

模型放入后再打开 Unity。缺少模型时只可阅读和测试源码，不能把空场景或占位几何当作数字孪生验收结果。模型坐标、关节顺序、单位和 Tool 1 偏置必须按现场版本复核。
