# 目录、技术路线与代码索引

本文描述**当前目录**，不是历史版本的能力承诺。
安全等级：
`显示/离线` 不向机器人发运动；
`只读` 可读取设备；
`受限真机` 可能发运动，须按现行现场验收流程操作；
`历史` 不作为当前入口。

## 一条数据怎样走

```text
Quest 右手柄 ─→ Unity Player(①) ─UDP 5005→ Python Quest 输入/校验
                                                │
                                                ▼
                                       ② 窗口 + 单独 SDK 进程
                                                │ 当前只处理 XYZ、保持 TCP 姿态
                                                ▼
                                    JAKA SDK 逆解筛查 + 厂商直线短段规划
                                                │
                                                ▼
                                          JAKA S5 真机
                                                │ 实测关节/TCP，而非目标点
                                                └─UDP 5006→ Unity 数字孪生
```

当前段间会停顿；“按时间采样并平滑衔接”仍是研究方案，不是已验收的运动实现。黄色点是目标，机械臂模型是实测反馈；两者不应混淆。DH116 三维模型可显示，但当前 ② 不控制灵巧手实物开合。技术与现场限制见[当前入口](../（0）程序入口说明.md)和[连续采样审查](连续采样遥操作_使用与审查.md)。

## 代码阅读顺序与不应误读的结论

先读 `quest_endpoint_teleop_gui.py` 的 `start/pump/stop_waiting`，再读 `连续采样位置遥操作.py` 的 `main` 和清理流程，再读 `sampled_follow.py` 的 `Settings/plan_segment/SampledFollower`，最后看 `quest_vr_input.py` 与 `single_owner_feedback.py`。每层只负责一类任务，遇到异常先看 `Validation/continuous_sampled_follow/` 的事件记录。

当前“短段运动平滑”是用户现场观察，不证明所有姿态、空间、速度或异常恢复安全；Unity 显示来自实测反馈，也不证明碰撞检测完备。公开发布前尚需：参数外置、第三方授权核查、移除本机敏感日志与绝对路径、独立机器的离线安装复现。
