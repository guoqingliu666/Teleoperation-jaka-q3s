# V1.5 全朝向候选：本次变更与验证边界

本次不切换伺服，不改变150 mm/s、400 mm/s²、30°/s运行档位。
新动态调度入口取消相对启动姿态30°限制；旧验收入口保持原范围。

## 实现

- 动态入口把姿态角距离范围设为180°。任意两个朝向的最短角距离都不超过180°，因此这代表全部朝向，并非关节可无限转圈。
- 输入映射按上一目标展开欧拉角，减少跨±180°的数值跳变；有序四元数轨迹仍保留中间朝向，不把一圈简化成相同起终点。
- 只读候选与真机候选采用相同姿态范围；原有有界接纳、自适应细分、厂商逆解、深度2规划队列不变。
- Unity显示绑定支持180°，并与Python一致使用会话中心限制最终朝向，而非限制Grip相对增量。
- 输入错误分别记录接收年龄、已处理样本间隔、位置变化和姿态变化；所有原有拒绝门槛保留。SDK阻塞期间缺少中间帧的问题尚未据此修复，不能声称消除了全部暂停。
