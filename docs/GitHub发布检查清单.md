## 发布边界

1. 远端仓库已选择MIT许可证；该许可证只覆盖本仓库自有源码，不改变第三方SDK、模型和CAD的权属。
2. JAKA SDK、DH116控制库与CAD源文件不提交。Windows Player作为本次可运行构建发布；其中模型与Unity运行时仍受各自权利人条款约束，不因MIT许可证改变权属。
3. 再检查将提交的文件中没有真实 IP、个人路径、设备序列号、采集图像、密钥或现场日志。文档里的历史地址也应脱敏。
4. 已在独立D盘目录进行干净归档/启动检查；真机复现仍必须提供匹配的厂家SDK和本机配置。

## 建议首次发布内容

- Python/Unity 源码、离线测试、配置模板、中文说明和安全事件复盘。
- 不附真机运动日志原文，只给脱敏后的汇总指标。
- 不附可直接连接现场控制器的本机配置。
- v1.0.0随仓库包含验收所用Player，下载源码ZIP后不需要另找Unity构建。

## 发布命令

提交前检查`git status`、大文件、敏感信息与离线测试；推送`main`后创建带注释的`v1.0.0`标签并验证远端哈希。
