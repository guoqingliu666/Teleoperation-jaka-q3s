## 发布前仍需人工决定

1. 远端仓库已选择MIT许可证；该许可证只覆盖本仓库自有源码，不改变第三方SDK、模型和CAD的权属。
2. 核实 JAKA SDK、JAKA URDF/STL、DH116 CAD/控制库、Unity Player 和图片的再分发授权。当前默认不提交这些文件。
3. 再检查将提交的文件中没有真实 IP、个人路径、设备序列号、采集图像、密钥或现场日志。文档里的历史地址也应脱敏。
4. 在一台没有现场 SDK/CAD 的干净 Windows 环境克隆，验证 README、Unity 工程打开、离线测试和缺失依赖提示。

## 建议首次发布内容

- Python/Unity 源码、离线测试、配置模板、中文说明和安全事件复盘。
- 不附真机运动日志原文，只给脱敏后的汇总指标。
- 不附可直接连接现场控制器的本机配置。
- Player 如需发布，确认授权后单独放 GitHub Release，不进源码历史。

## 最终发布命令（现在不要执行）
