# 源码安全分级

本仓库同时保存现行入口、只读诊断和历史研究代码。文件存在不等于已经取得真机放行；离线测试通过也不能替代控制器、现场和厂商验收。

## A：现行入口

- `①启动VR与JAKA数字孪生.cmd`：启动 Quest/Unity，并在②未运行时只读 JAKA；仅白名单读取接口，不发送运动。
- `②启动真机六维遥操作.cmd`：当前实际是**受限短段 XYZ 位置跟随**。姿态保持，无界连续跟随仍锁定。
- `Python/quest_endpoint_teleop_gui.py` 与 `Python/连续采样位置遥操作.py`：②的界面和唯一 SDK 子进程。
- `Python/src/vla_lab/sampled_follow.py`：当前已验收的短段检查、下发、停止和实测到位逻辑。

当前实验机已经完成单段、两段和五段受限验收。该结论只对应当时设备、Tool、负载、控制器配置和日志，不自动迁移到其他机器。

## B：只读或离线工具

- `只读工具_*.cmd`、`只读观察_*.cmd`：相机、状态和观察采集。
- `Python/只读检查*.py`：只有显式只读参数才连接设备，不发送运动。
- `Python/分析*.py`、`Python/tests/`：日志分析、离线故障注入和回归测试。
- `安全模拟_六维遥操作.cmd`：使用模拟机器人练习旧界面；默认地址为本机回环地址。

## C：历史真机实验代码，不是当前入口

以下代码用于追溯早期微动、单轴、目标点和事故调查。它们可能包含 `servo_j`、`servo_p`、`linear_move`、`joint_move`、`power_on` 或 `enable_robot` 调用：

- `Python/src/vla_lab/jaka_jog_controller.py`
- `Python/src/vla_lab/jaka_jog_gui.py`
- `Python/src/vla_lab/micro_teleop_gui.py`
- `Python/src/vla_lab/engineering_teleop_live.py`（真机模式已硬锁）
- `Python/真机验证新②_*.py`

这些文件不被根目录①/②调用。公共源码把它们的默认控制器地址改为 `127.0.0.1`；若人为传入真机参数，仍可能连接或运动，因此只能作为受审查的研究材料，不能按 README 日常步骤运行。

## 发布与修改原则

1. 发布说明不得把“短段验收通过”写成“六维连续遥操作完成”。
2. 不提交 `本机配置.cmd`、厂商 SDK、CAD/机器人模型、本机 Player、原始真机日志或设备地址。
3. 新的真机路线先增加离线与只读证据，再增加固定小范围验收档；不把影子规划结果直接变成运动许可。
4. 任何绕过 GUI 心跳、单 SDK 所有者、状态新鲜度或现场确认的修改，都必须视为新的高风险控制器重新验收。
