# v1.0.0 下载与复现

## 本版本包含

- ①、②两个中文入口及Python控制源码。
- Quest/OpenXR Unity工程源码。
- 本次真机验收使用的`Player_通信修复` Windows构建，包含数字孪生运行所需资源。
- 配置模板、离线测试、现场安全边界和事故复盘。

不包含JAKA厂家SDK、真实控制柜IP、真实`usersettings.ini`、CAD源文件、原始真机日志、密钥或设备序列号。

## 同一套设备恢复

1. 从GitHub下载`v1.0.0`并完整解压到D盘，例如`D:\ChatGPT\Projects\VR\Teleoperation-jaka-q3s-v1.0.0`。
2. 双击`验证第一版文件.cmd`，确认关键Player与控制文件哈希一致。
3. 安装Python依赖：`python -m pip install -r Python\requirements.txt`。
4. 复制`本机配置.example.cmd`为`本机配置.cmd`。
5. 在本机配置中填写匹配控制器的Python解释器、JAKA SDK目录、控制柜IP及从该控制器导出的`usersettings.ini`。
6. 双击①，确认Quest为`TRACKED`，数字孪生显示的是新鲜实测关节而非默认姿态。
7. 双击②，先执行30秒只读通信检查。通过后，按现场规程检查工具、负载、用户坐标系、急停和完整扫掠空间。
8. 先以低速度、小幅动作验证方向，再恢复v1.0.0的100mm/s正式六维参数。

## 可复现的含义

本标签固定了本次验收使用的项目源码、入口、参数门槛和Windows Player。真机结果还依赖控制器固件、厂家SDK、Tool 1、负载、机械安装、Quest/OpenXR运行时和现场网络。上述外部条件发生变化时，必须重新验收，不能仅凭相同Git标签直接放行运动。

## 验证基线

- 离线回归：253项通过，1项预期失败。
- 真机：100cm软件包络、100mm/s、400mm/s²、±30°、20°/s。
- 操作者结论：速度提升明显；方向与连续性正确；关节无突然大幅变化；无抖动、异响、报警或SDK超时。
